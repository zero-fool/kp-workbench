## 一、这是什么

KP 跑团工作台把主持人开团要用的一堆零散工具整合进一个应用，覆盖「**备团 → 开团 → 复盘**」全流程：

- **备团**：导入规则与背景、批量导入素材、AI 拆分登记生成七类资料卡、AI 编写剧本并分幕、布置地图与关系网、沉淀长期记忆；
- **开团**：资料卡即查即用、本地/联网骰娘检定、临场战斗回合追踪、剧本分幕进度推进（标记/伏笔兑现/现场备注）、一键生成开团清单；
- **复盘**：统计报表（档案构成 / 投骰热力图 / 活跃曲线）、运行记录、日志润色、AI 落地记录一键回滚。

| 板块 | 能做什么 |

| **工作台** | 人物卡 / NPC / 地区 / 日志 / 怪物 / 规则 / 背景 七类资料卡管理，多档案与备份、卡片模板（内置 CoC / DnD 规则书模板）、全局搜索、批量导入与 AI 拆分登记、卡片交叉引用与一键去重 |
| **骰娘工作台** | 自研 dice-core 骰娘内核：投骰台（通用 / CoC 7th / DnD 5e 规则插件）、连接中心（OneBot 11 / QQ 官方机器人 / 应用内测试通道，支持 QQ 直连与断线自动重连）、指令日志、文案与人设、插件工坊（含 AI 生成向导） |

## 二、核心功能一览

### 资料管理（工作台）

- **七类资料卡**：人物卡 / NPC / 地区 / 日志 / 怪物 / 规则 / 背景，字段随所选模板（CoC / DnD 等规则书模板）切换显示；
- **多档案与备份**：可建多个跑团档案，自动备份 + 数据快照回滚（删除误触保护、损坏数据自动自愈），换机交接可整包导出/导入；
- **效率工具**：全局搜索（跨全库全文检索一键跳转）、卡片模板系统（编辑/另存为模板、AI 依据规则书生成模板、AI 多卡提取勾选写入）、批量操作（多选批量删除/导出/收藏）、卡片交叉引用「被引用」徽标、自定义拖拽排序；
- **原始文本**：导入任意文本类文件后自动去乱码、保留结构，可一键调用 AI 在关键句后内联带团建议，不改动原文。

### 骰娘工作台（自研内核）

- **投骰台**：通用 / CoC 7th / DnD 5e 规则插件，本地离线可掷，掷骰永不依赖 AI；
- **连接中心**：OneBot 11 中转 / QQ 官方机器人 / 应用内测试通道三种接入方式；QQ 直连补齐断线自动重连闭环（指数退避重连、假在线巡检、登录错误按错误码分类提示），失败可一键切换中转；
- **插件工坊**：喂规则文本 → AI 生成 → 测试通道试跑 → 确认安装（两道闸、可回滚、可导出分享）；
- **指令**：.kp 指令原生读写工作台数据并与界面实时双向刷新；.ai 指令支持对话与定向判定（可取消、超时兜底）。

### 剧本分幕（v3.2.7 链路增强）

- **正文提取与清洗**：分幕前先筛选出真正属于剧本的部分，去装饰行、去多余空白（保留标点与结构），整理成干净正文并落盘为文件，再基于该文件分幕；
- **结构化分段**：按章节/段落/句末边界分段，跨段滚动回传人物/地点/线索锚点保证衔接，主块解析失败自动降粒度重分，尽量减少内容丢失；
- **逐幕落盘**：每幕要点自动保存为独立 txt，并支持一键打开所在文件夹，方便调用与导出；
- **节省 token**：缺失段可单独补跑（其余幕直接沿用）、指定一幕可单独重写并弹新旧对比确认，不必整本重分；
- **进度状态机**：每幕标记未开始/进行中/已完成/略过（自动顺位推进）、关键线索/伏笔兑现勾选、「本场待办」汇总未兑现伏笔、现场备注，开团时一键生成清单填入对话并复制到剪贴板。

### AI 能力（v3.2.7 成本与效果反馈）

- **成本透明**：每次分幕/补跑/重写实时显示本次 token 用量与预估成本，不再“用了多少心里没数”；
- **服务商健康度**：按模型汇总请求数 / 成功率 / 平均延迟 / 最近状态，一眼判断 AI 服务是否可用；
- **省钱优化**：AI 关系网推理按「共现次数 + 字段相似度」打分只注入 Top N、同输入走指纹缓存直接复用结果、支持 JSON 模式的接口优先强制结构化输出，减少无谓 token 消耗；
- **可靠兜底**：AI 返回 JSON 解析失败自动定向重试一次（受预算熔断保护）并记入诊断；AI 请求防重复（同一时间只放行一项，明确提示）。

### 其他亮点

- **临场战斗**：遭遇登记 → 回合追踪 → 逐单位血量/状态 → 结算标记，投骰自动并入遭遇流水；
- **地图**：Canvas 画板（底图/网格/标记/迷雾/椭圆区域/测量）、AI 依文字描述生成草案、导出 PNG；
- **关系网**：方向箭头、连线类型四色着色、框选多节点、视图工具、布局持久化、AI 补全关系；
- **统计分析**：档案构成、投骰时段热力图、近 30 天活跃曲线，可导出统计文本；
- **界面与性能**：5 套主题（含暮光护眼）、主题切换过渡动画、渲染层 esbuild 模块化、大图视口虚拟化、启动“窗口先出、数据后置”、全局快捷键（Ctrl+K 命令面板 / Ctrl+Shift+F 全局搜索 / Ctrl+N 新建卡片 / Ctrl+D 骰娘 / Ctrl+E 遭遇 / Ctrl+T 统计 / Esc 关闭浮层）。

## 三、快速上手

1. **下载**：从 [Releases](https://github.com/zero-fool/kp-workbench/releases) 下载绿色版 zip，解压到任意目录（建议路径不含中文与空格），双击 `KP跑团工作台.exe` 启动（首次运行遇 SmartScreen 选「更多信息 → 仍要运行」）；
2. **建档案**：进入「工作台」新建/导入一个跑团档案（也可把旧版数据自动迁移进来）；
3. **配 AI（可选）**：在「设置 → AI 配置」填入 OpenAI 兼容接口地址与 Key，即可使用资料生成、剧本分幕、润色等 AI 功能（不配置也能本地掷骰与管理资料）；
4. **备团**：导入规则与背景素材 → 批量导入/AI 拆分登记生成资料卡 → 可让 AI 编写剧本并分幕（要点自动逐幕落盘 txt）→ 布置地图与关系网；
5. **开团**：随开随查资料卡，投骰台掷骰（或接入 QQ 骰娘让群里直接骰），临场战斗开启回合追踪，剧本页推进各幕进度、勾选伏笔、记现场备注；
6. **复盘**：统计分析看数据，运行记录查日志，AI 落地记录不满意可一键回滚。

## 四、AI 能力与配置说明

- **兼容**：支持任意 OpenAI 兼容端点（接口地址 + API Key + 模型名），国内/国际服务商均可，可在设置中切换 JSON 模式等能力项；
- **配置位置**：应用内「设置 → AI 配置」，可随时修改并即时生效；
- **可关闭**：AI 行为有开关，可逐项关闭（资料生成、剧本分幕、润色等），关闭后不影响本地功能；
- **费用透明**：v3.2.7 起，每次 AI 任务实时显示 token 用量与预估成本，「AI 健康度」页按模型汇总请求数/成功率/平均延迟/最近状态；
- **提示词可编辑**：所有 AI 提示词模板可在设置中查看与改写，叙事风格可为全团设置并作为最高优先级注入每次对话；
- **数据边界**：AI 请求由你的 Key 直接发给所配端点，工作台本身不收集、不上传任何数据。

## 六、数据与隐私

- 数据全部落在本地 `data` 目录（绿色版 / 便携版默认 `%APPDATA%\KP跑团工作台\data`；在 exe 同级手动建 `data` 文件夹即可随包便携），不经过任何第三方服务。
- 应用内含自动备份与数据快照，仍建议定期整份复制 `data` 目录留底。
- 出问题时把 `data\runlog\latest.log` 发出来即可快速定位（应用内「更多工具 → 运行记录」可查看 / 导出）。

制作过程中确实参考过一些外部成果，凡有参考均在此列明：

| 参考对象 | 参考内容 | 说明 |
