## 一、这是什么

KP 跑团工作台把主持人开团要用的一堆零散工具整合进一个应用，覆盖「备团 → 开团 → 复盘」全流程：

| 板块 | 能做什么 |
| ---- | ---- |
| **工作台** | 人物卡 / NPC / 地区 / 日志 / 怪物 / 规则 / 背景 七类资料卡管理，多档案与备份、卡片模板、全局搜索、批量导入与 AI 拆分登记 |
| **骰娘工作台** | 自研骰娘内核：投骰台（通用 / CoC 7th / DnD 5e 规则）、连接中心（OneBot 11 / QQ 官方机器人 / 应用内测试通道）、指令日志、文案与人设、插件工坊（含 AI 生成向导） |
| **临场战斗** | 遭遇登记、回合追踪、逐单位血量与状态、结算标记 |
| **地图 / 关系网** | Canvas 画板（底图 / 网格 / 标记 / 迷雾）、关系网一键整理与关系清单 |
| **AI 助手** | 资料生成、剧本分幕与进度状态机、记录润色、长期记忆、提示词可编辑 |
| **统计分析** | 档案构成、投骰时段热力图、近 30 天活跃曲线、统计导出 |
| **系统** | 主题皮肤（含暮光护眼）、自动备份与快照回滚、运行记录、帮助中心 |

每个版本的更新内容见 [Releases](https://github.com/zero-fool/kp-workbench/releases)（即该版本的更新通告），应用内「更新公告」页有同一份完整更新日志。

## 二、下载与安装

在 [Releases](https://github.com/zero-fool/kp-workbench/releases) 页展开最新版本，选一个下载：

| 文件 | 类型 | 说明 |
| ---- | ---- | ---- |
| `KP-workbench-vX.Y.Z-green.zip` | **绿色版（推荐）** | 解压即用，免安装、不写注册表 |
| `KP-workbench-vX.Y.Z-portable.exe` | 便携版 | 单文件，双击运行 |
| `KP-workbench-vX.Y.Z-setup.exe` | 安装版 | 标准安装，支持原地覆盖升级不丢数据 |

绿色版三步：**解压到任意目录 → 双击 `KP跑团工作台.exe` → 首次运行如遇 SmartScreen 选「更多信息 → 仍要运行」**。

> 数据位置、备份迁移、升级不丢数据、常见问题等完整说明见 **[DOWNLOAD.md](DOWNLOAD.md)**。

## 三、数据与隐私

- 数据全部落在本地 `data` 目录（绿色版 / 便携版默认 `%APPDATA%\KP跑团工作台\data`；在 exe 同级手动建 `data` 文件夹即可随包便携），不经过任何第三方服务。
- 应用内含自动备份与数据快照，仍建议定期整份复制 `data` 目录留底。
- 出问题时把 `data\runlog\latest.log` 发出来即可快速定位（应用内「更多工具 → 运行记录」可查看 / 导出）。

## 四、参考与第三方说明

本项目整体为**自研实现**：骰娘内核、规则数据、界面与文案均为自行编写，**除下表明确列明的参考内容外，不复制、不捆绑任何第三方软件的代码、素材、插件包、台词、人设与品牌**；`npm run verify` 中的零第三方残留扫描（`tools/scan-thirdparty.js`）会在每次发布前强制校验发布产物中不含第三方可执行文件与素材。

制作过程中确实参考过一些外部成果，凡有参考均在此列明：

| 参考对象 | 参考内容 | 说明 |
| ---- | ---- | ---- |
| **DiceZone / Dice-Next**（AGPL-3.0 开源骰娘） | 骰娘指令的名称与写法习惯（`.ra` / `.rd` / `.en` / `.log` 等） | 为让用户沿用既有操作习惯，**参照其公开指令表对齐了指令的名称与写法**（指令语法属通行习惯，不涉及代码复制）。CoC 房规分档（0–7 号）与疯狂症状表（`.ti` / `.li`）均**依据 CoC 7th 公开规则自行实现**，未复制其源码或数据；程序整体运行于自研 dice-core 内核，不捆绑其可执行文件与素材。 |
| 第三方跑团工具「**枭雄**」 | 地图模块的界面格局与操作呈现风格（v2.4.0 起） | 仅参考交互与布局思路，未使用其代码、素材与数据格式 |
| **OneBot 11**（开放协议标准） | 骰娘连接 QQ 个人号的接入协议 | 采用社区公开协议标准实现，**不随包捆绑任何第三方协议端程序**，需用户自备合规协议端；不逆向 QQ 私有协议 |
| **QQ 官方机器人开放平台 API**（腾讯公开接口） | 骰娘接入官方机器人的通道 | 仅调用公开开放接口，自研适配 |
| **CoC 7th / DnD 5e** 规则体系 | 检定分档与规则插件的规则依据 | 使用公开的规则体系规则本身，条目内容自行撰写与整理 |
| **Electron / Chromium / Node.js** | 桌面运行时与打包基础 | 开源组件，随包附 `LICENSE.electron.txt`、`LICENSES.chromium.html` |
| 历史上的第三方骰娘内核 | v2.9.5 及更早版本曾内嵌第三方骰娘内核（约 149MB） | **已于 v3.0.0 彻底退役删除**，改为完全自研 dice-core 内核，现版本不含任何第三方可执行文件 |
