# 01 · 架构总览

## 1. 项目定位

KP 跑团工作台是一款 **Electron 桌面应用**，把 TRPG 主持人备团、开团、复盘全流程所需的工具整合进单机应用：

- 资料管理（人物卡 / NPC / 地区 / 日志 / 怪物 / 规则 / 背景 七类卡片）
- 骰娘工作台（自研 dice-core 内核 + 多种连接通道）
- 地图 / 关系网（Canvas）
- AI 助手（资料生成、剧本分幕、润色、长期记忆、提示词中枢）
- 临场战斗、统计分析、主题皮肤、自动更新

核心设计原则：

1. **数据本地自持**：所有资料保存在本地 `data` 目录，不经第三方服务器。
2. **骰娘内核自研**：v3.0.0 起彻底移除第三方骰娘内核，全部由 `src/dice-core` 实现。
3. **进程隔离**：主进程负责文件/AI/网络/更新，渲染进程只负责 UI，通过 IPC 与 preload 暴露的 `window.api` 通信。
4. **端口抽象**：`dice-core/ports` 定义契约接口，通道与主进程按同一契约实现，保证内核可脱离 Electron 单测。

## 2. 进程模型

Electron 采用经典三部分：

```
┌──────────────────────────────────────────────────────────────────────┐
│                          Electron 应用                                 │
│                                                                        │
│  ┌────────────────────────┐        IPC (contextBridge / ipcRenderer)  │
│  │       主进程 Main        │◀───────────────────────────────────────┐ │
│  │  src/main/main.js        │                                        │ │
│  │  · 窗口生命周期           │        ┌─────────────────────────────┐ │ │
│  │  · DataStore 数据读写     │        │   渲染进程 Renderer          │ │ │
│  │  · AI 请求 (ai.js)       │        │   src/renderer/*             │ │ │
│  │  · 自动更新 (updater)     │        │   · app.js   UI 主逻辑       │ │ │
│  │  · 骰娘运行时(装配 hub    │        │   · index.html 页面结构      │ │ │
│  │     + dice-net 通道)      │        │   · styles.css 样式          │ │ │
│  │  · PluginHost / Wizard   │        │   · dice-ui/* 骰娘 UI 组件    │ │ │
│  └──────────┬───────────────┘        └─────────────────────────────┘ │ │
│             │ require/直接调用                       ▲                 │ │
│             ▼                                       │ window.api      │ │
│  ┌────────────────────────┐              ┌──────────┴──────────────┐  │ │
│  │  dice-core（纯 Node）   │              │   preload.js             │  │ │
│  │  expr/calc/rules/brain  │              │   contextBridge 暴露      │  │ │
│  │  plugin/ports/reply...  │              │   window.diceCore + api   │  │ │
│  └──────────┬─────────────┘              └──────────────────────────┘  │ │
│             │ hub 装配                                                │ │
│             ▼                                                         │ │
│  ┌────────────────────────┐                                           │ │
│  │  dice-net（Channel）    │  OneBot11 / QQ官方 / sim / ws             │ │
│  └────────────────────────┘                                           │ │
└──────────────────────────────────────────────────────────────────────┘
```

- **主进程**：唯一能访问文件系统、网络与子进程的进程，也是所有 IPC 的注册中心。
- **preload**：桥接层。既通过 `contextBridge` 暴露渲染层可用的 `window.api` / `window.diceCore`，又在自身进程内 `require` 骰娘同步求值内核（零 IPC 可用于本地投骰面板）。
- **渲染进程**：纯 UI，禁止直接触达 Node；一切能力经 `window.api.*` 转发 IPC 到主进程。
- **dice-core / dice-net**：纯 Node 模块，不依赖 Electron，被主进程与 preload 共用，可脱离桌面环境跑单测。

## 3. 分层结构

```
┌───────────────────────────────────────────────────────────────┐
│  表现层   src/renderer/           index.html / app.js / styles │
│           src/renderer/dice-ui/   骰娘工作台专用组件            │
├───────────────────────────────────────────────────────────────┤
│  桥接层   src/preload.js          contextBridge + AI 请求守卫   │
├───────────────────────────────────────────────────────────────┤
│  应用层   src/main/               窗口 / IPC / 数据 / AI / 更新  │
│           src/main/updater/       GitHub Releases 自更新        │
├───────────────────────────────────────────────────────────────┤
│  内核层   src/dice-core/          骰娘内核（与 Electron 无关）   │
│           src/dice-net/           通道适配器（与 Electron 无关） │
├───────────────────────────────────────────────────────────────┤
│  契约层   src/dice-core/ports/    ChannelAdapter / StorePort …  │
├───────────────────────────────────────────────────────────────┤
│  持久层   data/（分片 JSON）+ backups/ + snapshots/             │
└───────────────────────────────────────────────────────────────┘
```

依赖方向自上而下，禁止反向依赖；契约层（ports）被内核层与通道层共同实现。

## 4. 关键数据流

### 4.1 骰娘消息流（核心链路）

```
玩家消息
  │
  ▼
ChannelAdapter（onebot11 / qqofficial / sim）   ← dice-net
  │  channel.onInbound(raw)
  ▼
createHub().handleInbound(channel, raw)         ← dice-core/hub
  │  ① normalizeMessage(raw, channel.id) → MessageIn
  │  ② await brain.handle(msg) → ReplyOut[]     ← dice-core/brain/CommandBrain
  │  ③ (可选) transformReplies 回复增强（AI 润色/随机插话）
  │  ④ channel.send(sessionId, reply) 逐条回发
  │  ⑤ emit('message') / emit('replies') 事件广播
  ▼
回复文本回到群/私聊；事件被主进程 dice-runtime 采集为指令日志
```

CommandBrain 内部：解析指令 → 权限校验（perm）→ 构建 CommandContext → 执行指令处理器（`brain/cmd/*`）→ 渲染（render）→ 返回 ReplyOut。

### 4.2 UI 数据流

```
用户操作（app.js）
  │ window.api.xxx(...)
  ▼
preload：aiGuard 包装（AI 类）+ ipcRenderer.invoke
  ▼
主进程 ipcMain.handle('xxx', ...)
  ▼
DataStore / ai.js / updater / diceWorkbench ...
  ▼
返回结果 → app.js 渲染；长任务通过 ipcRenderer.on 广播（ai:busy / import:progress / updater:state）
```

### 4.3 数据落盘流

```
store:save(doc)
  ▼
DataStore.save(doc)
  ├─ write()          原子写（tmp + rename），按 kind 分片写 data/kp-main/*.json
  ├─ maybeSnapshot()  变更即快照（去重、仅保留最近 N 份）→ data/snapshots/
  └─ backup()         定时/退出备份 → data/backups/
```

## 5. 目录结构

```
kp-workbench/
├─ package.json            # 元数据、脚本、electron-builder 配置
├─ README.md / DEPLOY.md / DOWNLOAD.md
├─ build/                  # 打包资源（图标）
├─ data/                   # 运行期数据（档案/备份/快照）
├─ docs/                   # 设计文档（specs / plans）与本 wiki
├─ src/
│  ├─ main/                # 主进程
│  │  ├─ main.js           # 入口：窗口 + 全部 IPC 注册
│  │  ├─ store.js          # DataStore：档案/分片/备份/快照
│  │  ├─ ai.js             # 工作台 AI（生成/解析/润色/审查…）
│  │  ├─ prompt-hub.js     # 提示词中枢（总提示词 + 场景覆盖 + 记忆）
│  │  ├─ exporter.js       # 导出（Word/PDF/Excel/Markdown…）
│  │  ├─ runlog.js         # 运行记录
│  │  ├─ dice-runtime.js   # 骰娘运行时装配（hub + 通道 + 日志）
│  │  ├─ dice-state-store.js # StorePort 主进程实现
│  │  ├─ dice-ai.js        # 骰娘 AI 桥接
│  │  ├─ dice-enhance.js   # 骰点润色 / 随机插话
│  │  ├─ dice-kp-advice.js # KP 带团建议
│  │  ├─ dice-memes.js     # 表情包库
│  │  ├─ dice-port.js      # AI 端口 / 通道装配辅助
│  │  └─ updater/          # 自更新（github/semver/zip/apply/index）
│  ├─ dice-core/           # 骰娘内核（纯 Node）
│  ├─ dice-net/            # 网络通道（纯 Node）
│  ├─ renderer/            # UI（index.html / app.js / styles.css / dice-ui）
│  └─ preload.js           # 桥接层
├─ tests/                  # node:test 单测 + 回归
└─ tools/                  # 接线审计 / 第三方扫描 / 基准 / 发布脚本
```

## 6. 主要子系统一览

| 子系统 | 目录 | 职责 |
| ---- | ---- | ---- |
| 主进程编排 | `src/main/` | 窗口、IPC、数据、AI、更新、骰娘运行时装配 |
| 骰娘内核 | `src/dice-core/` | 表达式求值、检定分档、指令处理、插件、端口、会话状态 |
| 网络通道 | `src/dice-net/` | QQ 直连 / OneBot 11 / QQ 官方 / sim / WebSocket |
| 渲染层 | `src/renderer/` | 全部界面与交互，`dice-ui` 为骰娘子面板 |
| 桥接层 | `src/preload.js` | `window.api` 契约 + AI 请求守卫 |
| 工具链 | `tools/` | 接线审计、第三方扫描、性能基准、发布 |
