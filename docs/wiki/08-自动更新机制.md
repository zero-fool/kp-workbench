# 08 · 自动更新机制

更新机制基于 **GitHub Releases**，**不依赖 `electron-updater` / `latest.yml` / blockmap 差分包**。应用检测最新 Release，按当前运行形态下载对应产物，校验后替换并重启。发布流程详见 [DEPLOY.md](file:///workspace/DEPLOY.md)。

代码位于 [src/main/updater/](file:///workspace/src/main/updater)，**纯 Node、不依赖 Electron**，便于单测（[tests/updater.test.js](file:///workspace/tests/updater.test.js)）。

## 1. 模块构成

| 文件 | 职责 |
| ---- | ---- |
| [index.js](file:///workspace/src/main/updater/index.js) | 编排与状态机：`check` / `status` / `download` / `apply` / `later` / `autoCheck` |
| [github.js](file:///workspace/src/main/updater/github.js) | 数据源与网络层：Release 查询、代理隧道、重定向、下载（含 Range 续传） |
| [semver.js](file:///workspace/src/main/updater/semver.js) | 版本解析与比较（零依赖） |
| [zip.js](file:///workspace/src/main/updater/zip.js) | 零依赖 ZIP 解压（含 CRC32 与安全防护） |
| [apply.js](file:///workspace/src/main/updater/apply.js) | 运行形态判定、可写性检测、helper 脚本替换与重启 |

## 2. 三种运行形态与更新策略

| 形态 | 判定依据 | 检测到新版后 |
| ---- | ---- | ---- |
| **绿色版** | 程序目录无 `Uninstall*.exe`（解压即用的文件夹） | 下载 `-green.zip` → 校验 `KP跑团工作台.exe` 与 `resources/app.asar` → 解压到暂存 → 退出后覆盖 `data/` 之外的文件并重启 |
| **便携版** | 存在环境变量 `PORTABLE_EXECUTABLE_DIR` | 下载 `-portable.exe` → 校验 PE 头（`MZ`）→ 退出后替换自身 exe 并重启 |
| **安装版** | 程序目录存在 `Uninstall*.exe` | 下载 `-setup.exe` → 校验 PE 头 → 交互式拉起安装程序（不静默）后退出 |

- 程序目录不可写时（如装到 `Program Files` 的绿色版）不做自动替换，界面退化为「打开下载页」手动更新（`apply.canWrite` → `snap.canAutoApply`）。
- 资产命名固定 ASCII，与 [tools/publish-github.sh](file:///workspace/tools/publish-github.sh) 一致：
  `KP-workbench-v<版本>-green.zip` / `-portable.exe` / `-setup.exe`。

## 3. 检测（check）

1. 请求 `https://api.github.com/repos/<owner>/<repo>/releases/latest`，取 `tag_name` / `body` / `assets`。
2. 匿名访问 API 易触发 403 限流 → 自动回退 **302 探测**：请求 `github.com/<owner>/<repo>/releases/latest`，从 `Location` 头解析 `vX.Y.Z`（只有版本号，资产地址按命名规范拼出）。
3. **预发布（prerelease）与草稿（draft）不参与比较**；版本按 `主.次.补丁[.更迭]` 逐段比较（`semver.isNewer`）。
4. owner/repo 常量写死在 [github.js](file:///workspace/src/main/updater/github.js)：`OWNER = 'zero-fool'`、`REPO = 'kp-workbench'`。**换仓库时必须同步修改**，并保证 `publish-github.sh` 指向同一仓库。

状态机 `snap.state`：`idle | checking | none | available | progress | staged | applying | err`。

## 4. 下载（download）

- 写临时文件 `<文件>.part`，支持 **HTTP Range 断点续传**。
- 完成后按 API 提供的 `size` 校验下载字节数。
- 下载加速前缀（镜像，如 `https://ghproxy.net/`）可在「更新设置」配置，下载请求自动拼接。

## 5. 校验与解压（green zip）

[zip.js](file:///workspace/src/main/updater/zip.js) 为零依赖实现：End of Central Directory → Central Directory → Local Header → `zlib.inflateRaw`，按块读取（不整包进内存）。防护：

- **CRC32 逐条校验**，损坏即报错；
- 拒绝 `..` / 绝对路径 / 盘符路径（防路径穿越）；
- 解压总量 ≤ 400MB、条目数 ≤ 20000（防 zip bomb）；
- 不支持加密与 Zip64（超出即明确报错）；
- 解压后剥掉顶层目录 `KP跑团工作台_vX.Y.Z_绿色版/`。

## 6. 替换并重启（apply）

1. 生成纯 ASCII 的 `.cmd` helper 脚本（路径经环境变量以 UTF-16 传入，避免中文乱码）。
2. `detached` 拉起 helper 后应用退出。
3. 脚本等待 exe 释放锁 → 覆盖文件 → `robocopy` 同步（绿色版用 `/XD data` 跳过数据目录）→ 重新启动。

## 7. 界面行为

- 启动约 1 分钟后静默检查一次（可在设置里关闭/调整间隔，默认 `DEFAULT_INTERVAL_HOURS = 24`）。
- 检测到新版后默认**自动下载**；下载完成弹窗询问「立即重启更新 / 稍后」，「稍后」可在「更新公告」页点「立即重启更新」。
- 上次更新未完成会在下次启动时提示。
- 开关与镜像前缀见「设置 → 关于 → 更新设置」。

IPC：`updater:check` / `status` / `download` / `apply` / `later` / `openRelease`，状态经 `updater:state` 广播到渲染层。

## 8. 网络与代理

[github.js](file:///workspace/src/main/updater/github.js) 内置网络层：

- 代理选择：显式参数 > `HTTPS_PROXY` > `HTTP_PROXY`（含小写）；命中 `NO_PROXY` 则直连。
- https 走 **CONNECT 隧道 + TLS**，http 走 CONNECT 隧道。
- 实现注意：Node 的 `http.request` 只有在**不传 `agent` 选项**时才采纳 `options.createConnection`；写 `agent:false` 会让 Node 自建 Agent 直连、代理失效——因此刻意不传 `agent`。
- 错误经 `humanError` 翻译成用户能看懂的话（限流、超时、DNS 失败、连接中断等）。

## 9. 发布前检查

1. 提升 `package.json` 的 `version`；同步修改 [app.js](file:///workspace/src/renderer/app.js) 顶部 `APP_VERSION`（`npm test` 校验二者一致）。
2. 在 `app.js` 的 `CHANGELOG` 补一条本次更新条目（同时是应用内「更新公告」与 Release 正文来源）。
3. 跑通 `npm test`（含 `tests/updater.test.js`）与 `npm run verify`。
4. 构建三种产物（见 [10-运行、构建与测试](10-运行构建与测试.md)）。
5. 用 [tools/publish-github.sh](file:///workspace/tools/publish-github.sh) 发布；Release 必须是 **latest 正式版**（草稿不可见、Pre-release 不参与）。

## 10. 数据安全保证

- **安装版 / 便携版**：数据在 `app.getPath('userData')`，与程序位置无关，覆盖升级不触碰数据。
- **绿色版**：数据在 exe 同目录 `data/`；替换脚本以 `/XD data` 跳过，升级不丢。
- 从旧绿色版切到安装版时，应用会把旧 `data/` 搬到用户目录。
